# POWERBI-DATA-VISUALIZATION-PROJECT
Power BI dashboard analyzing movies and TV shows data to uncover insights on content distribution, IMDb ratings, genres, runtime patterns, and release year trends through interactive visualizations.
Project Overview
<img width="1909" height="1008" alt="image" src="https://github.com/user-attachments/assets/5fa78f1f-48a0-4769-a784-a1562b926c08" />

This Power BI project analyzes movies and TV shows data to uncover trends in content distribution, IMDb ratings, genre popularity, and release year patterns. The dashboard transforms raw entertainment data into meaningful visual insights through interactive charts and business intelligence techniques.

Key Insights
Content Distribution
Movies significantly outnumber TV Shows in the dataset.
The platform's content library is primarily movie-focused.
Genre Analysis
Drama is the most common genre.
Comedy is the second most popular genre.
Thriller and Action also contribute a large share of content.
IMDb Rating Analysis
Most titles have IMDb ratings between 5 and 7.
Extremely high-rated and very low-rated titles are relatively rare.
Release Year Trends
Content production increased dramatically after 2000.
The highest concentration of titles appears in recent release years.
Rating Categories
Good (6–8): 43.54%
Average (4–6): 37.43%
Low (<4): 13.46%
Excellent (8+): 5.56%
Runtime vs IMDb Score
No strong relationship exists between runtime and IMDb score.
Longer content does not necessarily receive better ratings.
